What is supervised learning in machine learning?

Supervised learning trains a model on labelled data, where every input has a corresponding correct output. The goal is to learn the relationship between input features and the target variable.

NLP Preprocessing

What is tokenization in Natural Language Processing?

Tokenization is the process of breaking text into smaller units called tokens, such as words, subwords, or characters. It is a crucial initial preprocessing step because machine learning models cannot directly process raw text.

Modern NLP Tokenization

How do modern NLP models often handle tokenization for rare or unseen words?

Modern NLP models often use subword tokenization techniques, such as Byte Pair Encoding (BPE) or WordPiece, to handle rare or unseen words more effectively than traditional word-level tokenization.

Embedding Trade-offs

Why do contextual embeddings from BERT cost more to compute than static Word2Vec vectors?

Static vectors are looked up once per word, while contextual embeddings run the whole sentence through a transformer for every inference.
